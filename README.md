 Amazon-Sales-Data-Analysis-SQL-Project-
🔹 Overview  This project focuses on analyzing Amazon sales data using SQL to identify key business insights related to revenue, product performance, pricing, and customer behavior. The goal is to support data-driven decision-making by uncovering patterns and opportunities within the dataset.
🎯 Objective

The objective of this project is to explore sales data and answer key business questions related to:

Revenue drivers
Product and category performance
Pricing and discount strategies
Customer behavior
